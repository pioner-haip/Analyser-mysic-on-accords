# Chord Analyzer (ChordFinder)

Распознавание гитарных аккордов по WAV/MP3 (и MIDI) + интерфейс по вайрфреймам (Java Swing, без внешних библиотек, нужна Java 17+).

## Сборка и запуск

    # Linux / macOS                       # Windows (cmd)
    ./build.sh                            javac -encoding UTF-8 -d out src\chordfinder\*.java
    ./run.sh [файл.wav]                   java -cp out chordfinder.MainGui

Консольная версия (как раньше): `java -cp out chordfinder.Main`.
MP3/M4A/OGG/FLAC открываются, если в системе установлен `ffmpeg` (вызывается автоматически); без него — только WAV/AIFF/AU и MIDI.

## Тесты (без JUnit и без реальных записей)

    ./test.sh

* `DetectorSelfTest` — синтетическая «гитара» (Karplus–Strong) + бас + шум + «вокал» с заранее известными аккордами; проверяет число разных аккордов, число смен, точность по времени, темп.
* `SheetBuilderSelfTest` — построение листа «аккорды над текстом», транспонирование, упрощение.
* `FileE2E` — реальные файлы (WAV, 48 кГц стерео, MP3, MIDI) и экспорт.
* `UiSnapshot` — рисует экраны в PNG без окна (для проверки вёрстки).

## Что где

| Файл | Роль |
|---|---|
| `AudioChordDetector` | анализатор: хрома → тональность → Витерби → словарь песни → чистка (подробные комментарии в начале файла) |
| `ChordTemplateMatcher` | оценка «похоже ли на аккорд» (шаблоны + бас + бонус тональности) |
| `KeyEstimator`, `TempoEstimator` | тональность и темп |
| `MainGui` | окно, меню, фоновый анализ, перетаскивание файлов |
| `StartPanel`, `ResultPanel` | экраны 1 и 2 из вайрфреймов |
| `ChordSheetPanel`, `SheetBuilder` | лист «аккорды над текстом» (рисование и логика отдельно) |
| `ChordCard`, `ChordDiagramPanel`, `ChordLibrary` | карточки и схемы аппликатур (включая 7-аккорды) |
| `Song`, `Player` (+`WavPlayer`, `MidiPlayer`) | модель песни и воспроизведение с перемоткой |

## Параметры анализатора (`AudioChordDetector`, константы вверху)

* `SWITCH_COST` (4.0) — «цена» смены аккорда. Больше → стабильнее, но медленнее реагирует на быстрые смены.
* `MIN_SHARE` (0.06) — аккорд, звучащий меньше 6% песни, отбрасывается. Главная защита от «лишних» аккордов.
* `MIN_SEGMENT_SEC` (0.6) — отрезки короче приклеиваются к соседу.
* `SEVENTH_MIN_RATIO`, `SEVENTH_MIN_PERSIST` — строгость определения септаккордов.
* Отладка: `java -Dchordfinder.debug=true ...` печатает, как решается вопрос о септиме.

## Ограничения

Проверено на синтетике и сгенерированных файлах, не на реальных миксах. Ударные, вокал и густая аранжировка ухудшат результат;
режим «Упрощённые аккорды» (включён по умолчанию) надёжнее расширенного. Бой и ритм не распознаются.
Для текста с аккордами из скобок время аккордов оценивается равномерно, а не по слогам.
